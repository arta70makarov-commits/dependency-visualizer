## Общее описание

Инструмент на Python для построения и визуализации графа транзитивных
зависимостей Java-пакетов Maven. Программа читает YAML-конфигурацию,
загружает POM-файлы из Maven Central или локального каталога, строит граф
методом BFS без рекурсии и генерирует Mermaid-диаграмму.

## Возможности

* Чтение и валидация `config.yaml`.
* Загрузка POM из удалённого репозитория или локальной папки.
* Разбор Maven POM с учётом XML namespace.
* Разрешение версий через `<properties>`.
* Исключение test-scope зависимостей.
* Построение транзитивного графа BFS.
* Поиск обратных зависимостей по точной координате.
* Генерация `graph.mmd` для Mermaid.

## Настройки

|Параметр|Описание|
|-|-|
|`package\\\_name`|`groupId:artifactId` анализируемого пакета|
|`repo\\\_url`|URL Maven-репозитория или путь к локальному репозиторию|
|`test\\\_mode`|`true` — использовать локальный каталог POM|
|`version`|Версия корневого пакета|
|`max\\\_depth`|Максимальная глубина обхода BFS|

## Запуск

```bash
make build
make run
make test
```

Программа запускается модулем:

```bash
python -m src.main
```

Результат сохраняется в `graph.mmd`.

## Тестовый режим

```yaml
test\\\_mode: true
repo\\\_url: "./test\\\_repo"
```

В `test\\\_repo` должны лежать POM-файлы по пути:

```text
groupId/path/artifactId/version/artifactId-version.pom
```
